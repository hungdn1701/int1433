Server mở port và chờ trước, client chủ động kết nối tới

Server dùng hai loại socket: listening socket để chờ kết nối, và mỗi kết nối một connected socket để trao đổi dữ liệu.

Hệ điều hành thực hiện bắt tay, accept() chỉ lấy kết nối đã thiết lập

connect() trả về: bắt tay đã xong ở phía client. Chưa cho biết server đã gọi accept().

accept() không bắt tay. Nó lấy một kết nối đã thiết lập khỏi backlog và trả về connected socket.

Server mở port 9199, chờ một kết nối, đọc một dòng và trả lại một dòng

Javatry (ServerSocket listener = new ServerSocket(9199)) {  // passive open: mở port, chờ
    System.out.println("listening on port " + listener.getLocalPort());
    try (Socket connected = listener.accept()) {  // lấy một kết nối khỏi hàng đợi
        System.out.println("accepted: local port " + connected.getLocalPort()
                + ", client port " + connected.getPort());
        var in = new BufferedReader(new InputStreamReader(connected.getInputStream(), UTF_8));
        var out = new BufferedWriter(new OutputStreamWriter(connected.getOutputStream(), UTF_8));
        String line = in.readLine();  // đọc một dòng
        out.write("echo: " + line + "\n");  // trả lại một dòng
        out.flush();
    }
}

Câu lệnh new Socket thực hiện active open ở phía client

Javatry (Socket socket = new Socket("127.0.0.1", 9199)) {  // active open: kết nối tới server
    System.out.println("connected: local port " + socket.getLocalPort()
            + ", server port " + socket.getPort());
    var out = new BufferedWriter(new OutputStreamWriter(socket.getOutputStream(), UTF_8));
    var in = new BufferedReader(new InputStreamReader(socket.getInputStream(), UTF_8));
    out.write("hello\n");  // gửi một dòng
    out.flush();
    System.out.println("reply: " + in.readLine());  // đọc dòng trả về
}

Câu hỏi 1

Ở phía client, connect() vừa trả về thành công. Điều nào chắc chắn đã xảy ra?
A
Server đã gọi accept() và nhận được connected socket.
B
Bắt tay TCP đã xong ở phía client; kết nối có thể chưa được server lấy ra khỏi backlog.
C
Server đã đọc được dòng đầu tiên client gửi.
D
Server đã cấp một port mới riêng cho kết nối này.
Bắt tay do TCP trong hệ điều hành hai máy thực hiện. connect() trả về khi client gửi ACK; kết nối vào backlog khi ACK tới server; accept() lấy kết nối ra và có thể đến sau. Kết nối dùng chung port 9199 của server, không có port mới.
